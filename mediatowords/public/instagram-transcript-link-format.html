Which link should I paste for an Instagram transcript?

Paste the HTTPS address of one public Reel or video post. Media to Words accepts the forms instagram.com/reel/VIDEO_ID/ and instagram.com/p/VIDEO_ID/. Open the specific video, copy its address, and paste it into the Instagram transcript tool.

Seven checks with our actual link validator

On November 8, 2026, we ran the site's current link-validation function against seven constructed inputs. Each video example used the placeholder ID EXAMPLE123. We recorded whether the function returned a normalized address or rejected the input.

The ordinary Reel address and the version ending in ?igsh=example returned the same address. The function removed the query string while retaining the video ID. An input with spaces before and after it also returned the ordinary Reel address.

The post example used /p/EXAMPLE123/ and passed. The profile example used /example/, and the Story example used /stories/example/123/. Both were rejected. The plain HTTP example was also rejected because this input accepts HTTPS addresses.

What does an accepted address tell me?

It passes the first input check. Our experiment covered URL parsing. We used placeholder IDs, so the table provides no result for media retrieval or transcription. A real post must still be accessible and contain spoken audio for the subsequent steps to produce useful text.

What should I try if a copied link fails?

Open the address and confirm that it identifies the intended video. If the tool rejects the format, copy that video's HTTPS address again. If the format passes but retrieval fails, use the saved audio or video file with Upload file and continue from there.

Once you have text, check the final spoken sentence before exporting.
